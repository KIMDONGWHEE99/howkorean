# 브랜드 보이스 스킬

## 개요
이 스킬은 모든 커뮤니케이션이 일관된 브랜드 보이스, 어조, 메시지를 유지하도록 합니다.

## 브랜드 정체성

### 미션
팀이 AI로 개발 워크플로우를 자동화하도록 돕기

### 가치
- **단순함**: 복잡한 것을 단순하게
- **신뢰성**: 흔들림 없는 실행
- **역량 강화**: 사람의 창의성을 끌어내기

### 어조
- **친근하지만 전문적으로** - 가볍지 않으면서도 다가가기 쉽게
- **명확하고 간결하게** - 전문 용어를 피하고, 기술 개념은 쉽게 설명
- **자신감 있게** - 우리는 무엇을 하는지 잘 알고 있음
- **공감하며** - 사용자의 필요와 어려움을 이해하기

## 작성 가이드라인

### 해야 할 것 ✅
- 독자에게 말할 때는 "여러분"처럼 직접 부르기
- 능동태 사용: "보고서가 Claude에 의해 생성됩니다"가 아니라 "Claude가 보고서를 생성합니다"
- 가치 제안으로 시작
- 구체적인 예시 사용
- 문장은 20단어 이내로
- 명확하게 전달하도록 목록 사용
- 행동 유도 문구 포함

### 하지 말아야 할 것 ❌
- 기업식 전문 용어 쓰지 않기
- 가르치려 들거나 지나치게 단순화하지 않기
- "우리는 믿습니다", "우리는 생각합니다" 쓰지 않기
- 강조할 때가 아니면 영문을 전부 대문자로 쓰지 않기
- 빽빽한 글 덩어리 만들지 않기
- 독자에게 기술 지식이 있다고 가정하지 않기

## 어휘

### ✅ 선호하는 용어
- Claude("the Claude AI"가 아님)
- 코드 생성("auto-coding"이 아님)
- 에이전트("봇"이 아님)
- 간소화하다("혁신하다"가 아님)
- 통합하다("시너지를 내다"가 아님)

### ❌ 피할 용어
- "최첨단"(남용됨)
- "게임 체인저"(모호함)
- "레버리지"(기업식 표현)
- "활용하다"("쓰다"로 충분함)
- "패러다임 전환"(불명확함)

## 예시

### ✅ 좋은 예
"Claude가 코드 리뷰 과정을 자동화합니다. PR을 하나하나 직접 확인하는 대신 Claude가 보안, 성능, 품질을 리뷰해 팀의 시간을 매주 몇 시간씩 아껴 줍니다."

좋은 이유: 분명한 가치, 구체적인 이점, 행동 중심

### ❌ 나쁜 예
"Claude는 최첨단 AI를 활용해 종합적인 소프트웨어 개발 솔루션을 제공합니다."

나쁜 이유: 모호함, 기업식 전문 용어, 구체적인 가치 없음
